ForgeQuest v{{VERSION}}
=================

A cozy idle blacksmith game -- buy ore, forge it into swords on a crafting
grid, hammer them up in quality, and fill adventurer orders to grow your
smithy into something bigger. Discover fusion recipes, unlock passive
mines, hire hammers with special effects, and see how big a shop you can
build. Add friends by code to visit their workshop and help hammer their
ready crafts.

HOW TO RUN
----------
1. Make sure "ForgeQuest-{{VERSION}}.exe" and the "www" folder end up in
   the SAME folder together after unzipping -- don't separate them, the
   exe needs the www folder sitting right next to it to load the game.
2. Double-click ForgeQuest-{{VERSION}}.exe to launch.
3. That's it -- no installer, no account, no store.

"WINDOWS PROTECTED YOUR PC" WARNING
------------------------------------
This build isn't signed with a paid code-signing certificate, so Windows
SmartScreen will likely show a blue "Windows protected your PC" warning
the first time you run it, saying it's from an "unknown publisher." This
is expected for a small indie/test build, not a sign anything is
actually wrong. To run it anyway:

  Click "More info"  ->  then click "Run anyway"

REQUIREMENTS
------------
Windows 10/11 with the Microsoft Edge WebView2 Runtime, which is already
installed on most Windows 11 machines. If it's missing, Windows will
tell you and link you to get it -- it's a small, free Microsoft download.

YOUR PROGRESS
-------------
Your save is stored locally on your own PC and persists between launches
automatically -- that part is never uploaded anywhere.

FRIENDS
-------
The Friends tab talks to a small backend server so you can add people by
code and visit their workshop. A summary of what's on your crafting
grid (not your gold, gems, or inventory) syncs there so friends can see
it -- only people you've added and who've accepted a request back can
see it, nobody else.
